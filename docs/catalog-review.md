### 参照資料

すべて2026-09-14参照。以下の観測事項とカタログへの採用値は別物であり、台帳の理由も併せて読む。

- **tokyo-bath-2026** — [東京都浴場組合・入浴料金のお知らせ](https://www.1010.or.jp/guide/%E5%85%A5%E6%B5%B4%E6%96%99%E9%87%91%E3%81%AE%E3%81%8A%E7%9F%A5%E3%82%89%E3%81%9B/)。公式の料金表。2026年8月1日適用の大人600円、6〜11歳200円、6歳未満100円を確認。ページ冒頭に古い年号が残るが、更新注記と料金表の適用日は令和8年8月1日。全国の入浴施設へ一律適用していない。
- **yamaha-1998** — [1998年6月のヤマハ製品カタログのアーカイブ](https://guitar-catalog.com/acoustic-guitar/yamaha/1998/jp_index.html)、[クラシックギター掲載ページ](https://guitar-catalog.com/acoustic-guitar/yamaha/1998/pdf/10.pdf)。第三者が保存したメーカー原資料。検索で抽出されたCG170の税別45,000円の記載を桁の参考とした。全モデル・全ページの目視確認は未実施。架空の入門品19,800円や中古6,800円をこのカタログの掲載価格とはしていない。
- **beer-1968** — [ビール価格・年次統計](https://nenji-toukei.com/n/kiji/10031)。総務省の小売物価統計を出典とする**二次集計**で、1968年の大瓶小売価格126円を確認。店内の中瓶価格と同一条件ではない。180円への修正は、この数字と飲食店での提供を踏まえた推定。一次統計の原表は未照合。
- **bread-hansard** — [英国議会・The Price of Bread（1908-03-04）](https://api.parliament.uk/historic-hansard/commons/1908/mar/04/the-price-of-bread)。議会記録中の回顧説明に、1891年ロンドンの4ポンドのパン6.21d、1893年5¾dという記述がある。1890年の全英標準価格を示す資料ではない。ポンド単位の確認と近接年の価格例に限定し、二ポンド3〜4dは架空店の設定としている。

## 未確認範囲と次回の順序

自動走査で構造エラーは0件。英米の「小袋・小瓶」など、重量・容量が未指定の項目を94件検出した。これらは直ちに誤りという扱いにはせず、次回の分量設定と価格再確認の対象にする。現代の大半の店種と、英米の大半の個別価格は、今回実売資料・当時のメニューと照合していない。

1. **現代のスーパー・道の駅・コンビニ・飲食店**：特に米・卵・乳製品と昼食価格を優先。[農林水産省の米価格・販売動向](https://www.maff.go.jp/j/nousan/kokumotu/kome_kakaku.html)の最新週次資料などで、容量・地域・特売条件を揃える。今回は米の数値を確認できていないため据え置いた。
2. **昭和の居酒屋・パン・蕎麦・うどん**：一合／二合、主食／具材、パン一個／一斤の関係を重点点検。ビールは[昭和43年の鳥取県統計年鑑・物価](https://www.pref.tottori.lg.jp/secure/634607/b1968s43_18_butu.pdf)などの原表確認を進める。これらの原表の価格欄は今回未読。
3. **英国の食料品店・菓子店と米国の雑貨・菓子店**：`pnpm audit:catalog --json` の数量候補を順に確認。独自に量を決める場合は実物史料の再現と混同せず、根拠と量の決定理由を記録。
4. **1926年米国の食堂・書店・娯楽**：[NYPLのメニュー資料案内](https://www.nypl.org/research/support/whats-on-the-menu)から年代・都市・店格が一致する実物資料を探す。資料案内だけを個別価格の根拠にしない。
5. 以後は、実資料と未照合の「時代×店種」を先に、その後は最終照合日が古い順に回る。自動検査を通しただけの店種を「価格照合済み」に数えない。

## 毎月の作業手順

Codexのこのタスクに毎月1日9:00（日本時間）の巡回を設定。作業先はこのリポジトリ、公開先は既存のGitHub Pages。実行履歴はCodex側で確認する。

1. 作業中の差分・README・この記録を読み、`pnpm audit:catalog --json` で全件走査する。
2. 上記の未確認順序と前回の記録から対象店種を選び、現代は公式メニュー・メーカー・公的統計、歴史は設定年の一次資料を優先する。対象店舗ID、資料URL、参照日、資料の適用年月・地域・分量を記録する。
3. 明確な誤りを直し、不足する商品や条件を追加する。相場と違うだけで特色や価格を均一化しない。判断できない項目は理由付きで次回へ回す。店舗・商品IDを保持する。
4. `docs/reviews/YYYY-MM-DD.json` に変更前後・理由・確認範囲を残し、このページの件数・未確認範囲・次回順序とHelp・更新履歴を更新する。
5. `pnpm build` → `pnpm test` → `pnpm audit:catalog` → `pnpm check:pages` を通す。公開先とGit差分を確認して既存mainへ反映し、GitHub Actionsの公開完了を確認する。
6. 修正・追加・公開の成果、失敗、ユーザーの対応が必要な場合だけ通知する。変化がなければ静かに終了する。

正本は `src/data/shops/*.json`。`scripts/era-shop-drafts.json` には元の21項目の修正を同期した。初期投入スクリプトは既存店舗をスキップするため、月次の追加商品・店舗条件の再生成には使わない。今回の移行スクリプトは適用済み台帳があると停止する。索引と公開JSONはビルドで再生成する。
