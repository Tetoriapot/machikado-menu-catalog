# まちかどメニュー帖

現代日本と4つの歴史設定で使う、創作・TRPG向けの架空店舗メニューカタログ。React + TypeScript + Viteで動く静的SPAです。サーバー、DB、APIキー、利用者登録は不要です。

## 収録内容

- 76カテゴリ、315店舗、6,619商品・サービス。全店舗に21項目以上。件数は店舗間の重複を含む延べ数です。
- 現代は65カテゴリ・195店舗・4,099項目。従来の店舗・商品・ID・情景は保持し、お気に入りと卓の保存内容をそのまま使えます。
- 平成（1998年）、昭和（1968年）、ヴィクトリア朝イギリス（1890年）、1920年代のアメリカ（1926年）を追加。各時代10店種・30店舗・630項目、合計120店舗・2,520項目です。
- 歴史店舗は同じ時代・店種に3店舗。各店の21項目は共通18品と固有の名物3品で構成し、店内・接客・名物・街とのつながりを収録しました。
- 11店種を新設：ティールーム、パブ、チョップハウス、フィッシュ＆チップス、菓子店、裁縫用品店、食料品店、ダイナー、ソーダファウンテン、デリカテッセン、ステーキハウス。
- 時代は通常「現代」。初回表示・再読込・絞り込み解除で現代に戻り、時代を選ぶとその時代だけを検索・抽選します。歴史店舗への直接リンクでは該当時代を表示します。2010年代・2000年代・1990年代と「すべての時代」の選択肢は削除しました。
- 時代に合わせてカテゴリ一覧・タグ・店舗件数が変わります。時代変更時はカテゴリ・タグ・商品予算を解除し、異なる通貨の予算を引き継ぎません。
- 日本は円、イギリスは旧英国通貨、アメリカは米ドル。コピー・PL表示・印刷・各保存形式でも通貨を維持します。歴史店舗の価格は史料の転記や現代価格の換算ではなく、卓で使う架空設定です。[収録方針と参考資料](docs/historical-catalog.md)を参照してください。
- **編集用の初稿です。人による最終確認済みとはしていません。** 実店舗の商品一覧の転載はしていませんが、店名が実在店舗と偶然一致しないことを保証するものではありません。

## 利用できる機能

- 商品・店舗・説明・タグの全文検索（空白区切りAND、表記ゆれを正規化）。一致した商品名と価格を結果に表示し、その商品へ直接移動できます。
- カテゴリ・店舗価格帯・商品価格上限・立地・規模・時代・タグで絞り込み。現在の条件を保持した店舗の再抽選と、卓ごとの使用済み店舗の除外。
- おすすめは料理・飲料・物販から最大3品。料金・サービス・追加商品は抽選から除外し、分類の偏りを抑えます。
- PLメニュー表示、閲覧専用URL、全画面、操作非表示。単体HTMLを渡せば、受け手はログイン・通信なしで閲覧できます。
- 商品の複数選択と各1点の合計、名前と価格だけの短文コピー、説明付きコピー、おすすめコピー、GM用コピー。GM用テキストには店内・接客・名物・地域とのつながりと価格補足も含めます。
- 出力設定で店名・対象商品・説明の有無・文字サイズ・縦横を指定。印刷（ブラウザのPDF保存を含む）、HTML・PNG・SVG・CSV・JSON保存。画像は紙面全体を1枚にします。
- セッションごとの店舗一覧、店名の別名、GMメモ、使用済み店舗。お気に入り・最近20店舗・セッションをJSONで書き出し、別端末へ追加読み込みできます。競合するセッションは別名で残し、既存メモを上書きしません。

保存先はブラウザ内のLocalStorageです。卓を作成せずに抽選した店舗はSessionStorageに保存します。端末間の自動同期はありません。保存が拒否された場合はメモリ内で動作し、その旨を表示します。クリップボードが拒否された場合は選択可能なテキストを表示します。

セッションの保存ファイルにはGMメモが入ります。PL用HTML・画像・CSV・JSONには商品と店名・通貨・価格補足を出力します。閲覧専用URLは元の店舗情報を表示し、端末内の別名や商品選択は持ち出しません。

PL表示で操作を隠した場合、画面上端をタップ、キーボードで上端のボタンをフォーカス、またはEscで戻せます。全画面中のEscはブラウザ側の解除が優先されます。

## 開発

Node.js 22.13以降とpnpmを使います。

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
pnpm start
```

この環境の依存関係はロックファイルで固定しています。利用しないネイティブビルドスクリプトは`pnpm-workspace.yaml`で無効にしています。

## データの追加

正本は`src/data/shops/<category-id>.json`です。UIに商品・店舗データを直書きする必要はありません。

```json
{
  "category": { "id": "kissaten", "label": "純喫茶", "group": "飲食店", "icon": "coffee" },
  "shops": ["Shop型のオブジェクトを追加（src/data/types.ts参照）"]
}
```

1. 同じカテゴリに増やす場合は`shops`配列へ追加。新カテゴリは同形式のJSONファイルを作成。
2. 店舗・セクション・商品のIDを一意にする。価格は円・旧英国ペンス・米セントの非負整数（小数は使わない）。店舗ごとに21商品以上を設定。商品にkind（food/drink/goods/addon/fee/service）を付け、必要ならrecommendationGroupと店舗のpriceNoteを設定。
   現代は省略時にJPYとして扱います。歴史店舗にはera・currency・setting（year/place）・priceNoteを指定してください。円とセントと旧ペンスを混在させず、価格補足で単位を示します。
3. `pnpm build`または`pnpm dev`で検索索引と配信用JSONを再生成。
4. `pnpm test`で検索・コピー・履歴・データ整合性を確認。

歴史店舗の追加原稿は`scripts/era-shop-drafts.json`、反映用の処理は`scripts/add-era-shops.ts`です。40組の時代・店種ごとに3店舗を追加し、登録済みIDはスキップします。登録後の編集は正本のJSONで行います。

新カテゴリの追加原稿は`scripts/new-category-drafts.json`、反映用の処理は`scripts/add-new-categories.ts`です。カテゴリ・三店舗・共通12品・各店独自9品を検証してから、未登録カテゴリだけを追加します。再実行では登録済みカテゴリを変更しません。以後の編集は正本のJSONで行います。

従来の50カテゴリの第三店舗の原稿は`scripts/third-shop-drafts.json`、反映用の処理は`scripts/add-third-shops.ts`です。各カテゴリの`-3`店舗を追加し、追加済みならスキップします。

先行した商品増補の原稿は`scripts/catalog-expansion.json`、反映用の処理は`scripts/expand-catalog.ts`です。この処理と`scripts/enrich-catalog.ts`は当初の`-1`・`-2`店舗だけを対象にし、第三店舗は変更しません。増補済みのデータを再度追加することはありません。

`src/data/generated-index.json`と`public/data/`は自動生成物です。直接編集しません。商品検索用の名称・価格・説明を含む索引を初期読込し、セクション別の店舗資料は店舗選択時にカテゴリ単位で取得・キャッシュします。一覧のDOMは18店舗ずつ追加します。

## 静的公開

`pnpm build`が作る`dist/`をGitHub Pages、Cloudflare Pages、Netlify、Vercelなどへ配置できます。`base: './'`とハッシュルーティングのため、サブディレクトリ公開とページ再読込に対応し、サーバーのリライト設定は不要です。

- 店舗URL: `https://example.com/#/shop/kissaten-1`
- GMから開くPL表示: `https://example.com/#/shop/kissaten-1?mode=pl`
- 閲覧専用URL: `https://example.com/#/menu/kissaten-1`
- 商品への直接リンク: `https://example.com/#/shop/kissaten-1?item=商品ID`
- カテゴリ: `https://example.com/#/categories/izakaya`

`file://`での直接起動は、メニューデータ取得がブラウザに制限されるため対象外です。HTTPサーバーで配信してください。Sitesの所有者限定公開はホスティング側のアクセス制御を使います。一般公開の静的ホストではログイン不要で動作します。

## 検証と残る範囲

データの件数・ID一意性・価格・説明・静的ファイルの一致と、検索、複合フィルター、ランダム、コピー、保存値の復元、履歴上限、URL解釈を自動テストします。歴史拡張では各時代30店舗、現代が既定の検索・抽選、舞台年と通貨、旧通貨の桁上げ、価格上限と全出力の単位維持、全315店舗の保存復元を追加検証します。TypeScriptと本番ビルドも確認します。

画面操作を伴うブラウザQAは未実施です。全画面・クリップボード・印刷ダイアログの実挙動はブラウザに依存します。WebMCPの検索・読み取りを対応ブラウザで登録しますが、対応検証環境がないためWebMCPの実機確認は未実施です。通常の操作には影響しません。

拡張分では、各カテゴリ三店舗と独自商品の件数、新店舗の検索・URL・保存・配布物の連携、商品一致と価格条件、配布ファイルの入力エスケープ、優先カテゴリの差分、おすすめからの料金除外、バックアップの検証と競合処理、使用済み除外、選択内容と各出力の一致、CSVの数式対策を検証します。

PNG保存・ダウンロード・印刷の端末上の動作確認は未実施です。画像と印刷用HTMLは組版が多少異なります。大きなPNGは端末のメモリ消費を抑えるため縮小します。

自由な店舗ジェネレーター、全商品データのユーザー編集、端末間の自動同期は対象外です。
